# eb_automatizaciones - Sitio Web Oficial

Sitio web corporativo y de conversión desarrollado para **Emilio Ballistreri** (**eb_automatizaciones**).

## 🚀 Tecnologías
- **HTML5 Semántico**: Estructura accesible y optimizada para SEO.
- **CSS3 Moderno**: Diseño futurista inspirado en el logo (Dark Obsidian, Electric Blue, Cyan Glow), efectos glassmorphism y responsive design.
- **JavaScript Nativo**: Animación de red de circuitos tecnológicos en Canvas, menú mobile, scroll suave, estimador interactivo en 3 pasos, FAQ con acordeón y enlace dinámico a WhatsApp y Email.
- **SEO & Indexación**: Datos estructurados Schema.org JSON-LD (`ProfessionalService`), `robots.txt` y `sitemap.xml`.

## 📁 Estructura del Proyecto

## 💻 Visualización Local
Para abrir el proyecto localmente podés:
1. Abrir directamente el archivo `index.html` con cualquier navegador (doble clic).
2. O iniciar un servidor local con:
```bash
python -m http.server 5173
```
Y navegar a `http://localhost:5173`.
